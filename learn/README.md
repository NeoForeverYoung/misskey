# Misskey 学习文档

本目录包含对Misskey项目的学习和分析文档，帮助开发者更好地理解Misskey的架构和实现。

## 文档目录

1. [项目结构概述](./01-项目结构概述.md) - Misskey项目的整体结构和技术栈
2. [后端架构详解](./02-后端架构详解.md) - 后端代码组织和主要模块解析
3. [数据模型与存储](./03-数据模型与存储.md) - 数据库模型和存储机制
4. [帖子系统详解](./04-帖子系统详解.md) - 帖子(Notes)的创建、存储和交互
5. [本地部署指南](./05-本地部署指南.md) - 如何在本地环境中部署和调试Misskey
6. [评论与互动](./06-评论与互动.md) - 评论、回复、嵌套评论的实现机制
7. [用户系统](./07-用户系统.md) - 注册和登录功能的实现

这些文档基于对Misskey源代码的分析，旨在帮助开发者快速理解项目结构，为二次开发提供参考。
