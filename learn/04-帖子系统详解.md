# Misskey 帖子系统详解

Misskey的核心功能是发布帖子（Notes），这是用户在平台上分享内容的主要方式。本文档将详细介绍Misskey的帖子系统，包括其设计原理、数据结构、API实现和前端展示。

## 帖子数据模型

帖子在Misskey中称为"Note"，其数据模型定义在`packages/backend/src/models/Note.ts`中：

```typescript
@Index(['userId', 'id'])
@Entity('note')

    @Column('text', {

    @Column('varchar', {

    public name: string | null;

    @Column('varchar', {
        length: 512, nullable: true,
    })
    public cw: string | null;

    @Column({
        ...id(),
        array: true, default: '{}',
    })
    public fileIds: MiDriveFile['id'][];

    @Column('boolean', {
        default: false,
    })
    public localOnly: boolean;

    // 回复字段
    @Index()
    @Column({
        ...id(),
        nullable: true,
        comment: 'The ID of reply target.',
    })
    public replyId: MiNote['id'] | null;

    @ManyToOne(type => MiNote, {
        onDelete: 'CASCADE',
    })
    @JoinColumn()

        ...id(),
        nullable: true,

    @Column('varchar', {
        length: 128, nullable: true,
        comment: '[Denormalized]',
```

## 帖子类型

Misskey的帖子系统支持多种类型：

1. **普通帖子**：包含文本和/或媒体内容的基本发布
2. **回复**：对另一个帖子的回复（设置`replyId`）
3. **转发**：对另一个帖子的转发（设置`renoteId`）
4. **引用转发**：转发并添加额外评论
5. **投票帖子**：包含投票选项的特殊帖子

## 时间线系统

Misskey的时间线系统是帖子流的主要显示方式，核心实现在`packages/backend/src/core/TimelineService.ts`：

```typescript
@Injectable()
export class TimelineService {
    @bindThis
    public async getTimeline(userId: MiUser['id'], options: {
        untilId?: string;
        sinceId?: string;
        limit?: number;
        includeReplies?: boolean;
        includeMyRenotes?: boolean;
        withRenotes?: boolean;
    }) {
        const query = this.generateQuery(userId, options);
        // 根据查询选项构建数据库查询
        
        return await query.take(options.limit).getMany();
    }

    private generateQuery(userId: MiUser['id'], options: {...}) {
        // 构建时间线查询
        const query = this.notesRepository.createQueryBuilder('note')
            .where('note.visibility = :visibility', { visibility: 'public' })
            .orWhere(/* 其他可见性条件 */);
            
        // 添加时间范围条件
        if (options.untilId) {
            query.andWhere('note.id < :untilId', { untilId: options.untilId });
        }
        
        if (options.sinceId) {
            query.andWhere('note.id > :sinceId', { sinceId: options.sinceId });
        }
        
        // 处理回复和转发选项
        if (!options.includeReplies) {
            query.andWhere('note.replyId IS NULL');
        }
        
        if (options.withRenotes === false) {
            query.andWhere('note.renoteId IS NULL');
        }
        
        // 其他过滤器
        
        // 按时间排序
        query.orderBy('note.id', 'DESC');
        
        return query;
    }
}
```

Misskey支持多种时间线：

1. **主页时间线**：来自用户关注对象的帖子
2. **本地时间线**：来自用户所在实例的帖子
3. **全局时间线**：包括联邦宇宙中其他实例的帖子
4. **探索**：推荐和热门帖子

## 反应与交互

Misskey的帖子支持多种交互方式：

### 点赞与反应

用户可以使用多种表情符号对帖子进行反应，实现在`packages/backend/src/core/ReactionService.ts`：

```typescript
@Injectable()
export class ReactionService {
    @bindThis
    public async create(user: MiUser, note: MiNote, reaction: string) {
        // 确保反应正确转换为Unicode 或自定义表情符号
        
        // 检查是否已经存在反应
        const exist = await this.noteReactionsRepository.exists({
            where: {
                noteId: note.id,
                userId: user.id,
            },
        });
        
        if (exist) {
            // 修改现有反应
            await this.delete(user, note);
        }
        
        // 创建新反应
        await this.noteReactionsRepository.insert({
            id: this.idService.gen(),
            noteId: note.id,
            userId: user.id,
            reaction,
        });
        
        // 更新帖子反应计数
        await this.notesRepository.increment({ id: note.id }, 'reactionsCount', 1);
        
        // 更新此表情符号的计数
        const record = await this.notesRepository.findOneBy({ id: note.id });
        const reactions = record?.reactions ?? {};
        reactions[reaction] = (reactions[reaction] ?? 0) + 1;
        await this.notesRepository.update(note.id, {
            reactions,
        });
        
        // 发送通知
        this.globalEventService.publishNoteStream(note.id, 'reacted', {
            reaction,
            userId: user.id,
        });
        
        // 给作者发送通知
        if (note.userId !== user.id) {
            this.notificationsService.createNotification({
                notifierId: user.id,
                notifieeId: note.userId,
                type: 'reaction',
                noteId: note.id,
                reaction,
            });
        }
    }
}
```

```vue
  const endpoint = getEndpoint();
  const params = {
    limit: 20,
    untilId: untilId.value,
  };
  
  const fetchedNotes = await misskey.api.request(endpoint, params);
  if (fetchedNotes.length === 0) {
    more.value = false;

    untilId.value = fetchedNotes[fetchedNotes.length - 1].id;

function getEndpoint() {
  switch (props.src) {
    case 'home': return 'notes/timeline';
    case 'local': return 'notes/local-timeline';
    case 'global': return 'notes/global-timeline';
    case 'user': return 'users/notes';
    default: return 'notes/timeline';
  }
}

  fetchNotes();
}

  fetchNotes();
  
  // 订阅实时更新

  connection.on('note', (note) => {
    notes.value.unshift(note);
  });
});

  notes.value = [];
  untilId.value = null;
  more.value = true;
  fetchNotes();
});
```

## 联邦宇宙支持

Misskey通过ActivityPub协议支持跨实例互动。帖子创建后可能需要联邦到其他实例：

```typescript
// 联邦发布帖子
@bindThis
public async federateNote(note: MiNote) {
    if (note.visibility === 'followers' && !note.localOnly) {
        this.deliverToFollowers(note);
    } else if (note.visibility === 'public' && !note.localOnly) {
        this.deliverToPublic(note);
    }
}

// 向关注者发送
@bindThis
private async deliverToFollowers(note: MiNote) {
    const followers = await this.followersRepository.find({
        where: {
            followeeId: note.userId,
            followerHost: Not(IsNull()),
        },
    });
    
    for (const follower of followers) {
        this.queueService.deliver(follower.followerInbox, this.renderActivity(note));
    }
}
```

## 小结

Misskey的帖子系统是一个复杂而全面的实现，具有以下特点：

1. **灵活的数据模型**：支持文本、媒体、投票等多种内容类型
2. **层次化的回复系统**：通过`threadId`跟踪对话和评论链
3. **丰富的互动功能**：支持点赞、转发和多种表情反应
4. **实时更新**：通过WebSocket流提供即时通知
5. **联邦支持**：通过ActivityPub协议与其他Fediverse实例互通

Misskey的帖子系统结合了传统微博与现代社交媒体的特性，同时支持去中心化的联邦功能，为用户提供了灵活、强大的内容分享体验。
